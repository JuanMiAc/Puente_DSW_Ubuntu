## Ciclo de una petición en Laravel
1. El navegador realiza una petición HTTP.
2. La petición entra por `public/index.php`.
3. Laravel inicializa la aplicación.
4. El router busca una ruta compatible.
5. La ruta ejecuta código o devuelve una vista.
6. Blade genera HTML en el servidor.
7. Laravel devuelve una respuesta HTTP.
8. El navegador interpreta el HTML.
